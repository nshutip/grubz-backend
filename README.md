# Grubz Backend 🍽️

Grubz is a community-first food and vendor platform designed to power cafeteria services and food ordering within organizations and campuses. This repository contains the backend API, built with **Node.js**, **Express**, **PostgreSQL**, and **Sequelize**.

---

## 🚀 Tech Stack

- **Node.js** + **Express** – RESTful API server
- **PostgreSQL** – Relational database
- **Sequelize ORM** – Database modeling & migrations
- **JWT** – Authentication & Authorization
- **Role-Based Access Control (RBAC)** – User roles: `community-admin`, `vendor`, `customer`
